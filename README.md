# Assignment01-GitHub-Basics
Assignment01 - Getting started with GitHub: C++ program for sum of first 50 natural numbers
## Program Description
This C++ program calculates the sum of the first 50 natural numbers using two methods.
### Method 1: Using a Loop
A for loop adds all numbers from 1 to 50.
### Method 2: Using a Formula
The formula n(n+1)/2 is used to calculate the sum and verify the loop result.
## Program Output
Sum of first 50 natural numbers (loop): 1275
Sum using formula n(n+1)/2: 1275
## Programming Language
C++
## Learning Outcomes
* Practiced using for loops in C++.
* Learned to calculate a sum using a mathematical formula.
* Learned how to edit files and create commits on GitHub.
